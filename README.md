# VMC with PGCS

Variational Monte Carlo with point group correlated sampling (for force estimators)

## Installation
Install directly from the remote repository:
```bash
pip install git+ssh://git@github.com:myung-group/vmc-pgcs.git
```
Install from the local repository (cloned with `git`):
```bash
pip install .
```
Or in (local) development mode:
```bash
pip install -e .
```

## Usage
```bash
python test/test_H2.py
```
